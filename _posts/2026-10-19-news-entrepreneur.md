Anthropic が株式の5%を公益基金に拠出すると発表した。AI 業界では、破産した Character.AI の人材を Disney が引き取り、Microsoft は英国のデータセンター計画から手を引くなど、資金と人材の動きが激しい。国内では AI 法の改正議論が動き出している。

1. [Anthropic、株式5%を公益基金へ](https://www.nikkei.com/article/DGXZQOGN182N70Y6A011C2000000/) (日経・会員限定)<br>
   企業価値が大きく上がれば追加で2%を出せる仕組みで、AI による失業者の支援や NPO への寄付に充てる。

2. [Disney、破産した Character.AI の人材の過半を採用へ](https://techcrunch.com/2026/10/18/disney-agrees-to-hire-the-majority-of-character-ais-workforce/) (TechCrunch・英語)<br>
   続報（10/14掲載）。60人超に年間約6000万ドルの報酬を提示し、大半が受諾。ただし対抗入札の余地は残る。

3. [Microsoft、英新興 nScale とのデータセンター計画から撤退](https://www.nikkei.com/article/DGXZQOGR182GJ0Y6A011C2000000/) (はてブ・会員限定)<br>
   電力の接続が遅れたことが背景で、AI クラウドを手掛ける nScale の上場計画に影を落とす。

4. [Elorian、画像を見返しながら考える初のモデル「Glimpse」](https://techcrunch.com/2026/10/16/elorians-first-ai-model-wants-to-reason-with-images-not-just-about-them/) (TechCrunch・英語)<br>
   製品発表前に評価額3億ドルで5500万ドルを集めた新興が、推論の途中で画像を切り出す方式を打ち出した。

5. [DeepSeek、検索と取得の API を公開](https://api-docs.deepseek.com/guides/search/) (HN・英語)<br>
   自社の検索エンジンを使い、エージェント向けに Web 検索とページ取得を JSON の API で提供。成功1000件あたり0.75ドル。

6. [Linear の創業者が語る「ソフトウェアの向こうにいる人」](https://karrisaarinen.com/posts/someone-behind-the-software/) (HN・英語)<br>
   データより直感を重んじる Linear の流儀を、製品づくりの自動化が進む今の文脈で説く。

7. [リーダーシップなき越境は組織を壊す](https://note.com/srt_taka/n/nff6c2d40c11b) (はてブ)<br>
   Slack で8人が50件やり取りしても何も決まらない現象を、具体化と抽象化の非対称から説明する管理職の自省録。

8. [動き出す AI 法改正、規制と利活用を霞が関でどうまとめるか](https://www.nikkei.com/article/DGXZQOUA13A680T11C26A0000000/) (日経・会員限定)<br>
   司令塔は古川デジタル相だが、関係省庁のスタンスは揃っておらず、海外の規制強化との釣り合いが焦点になる。

9. [子どもは SNS 禁止を突破する、それを塞ぐべきではない](https://www.technologyreview.com/2026/10/16/1146834/kids-are-outsmarting-social-media-bans-thats-not-a-problem-we-need-to-solve/) (MIT TR・英語/一部会員限定)<br>
   豪州では16歳未満の5人に4人が禁止後も利用していたとの調査を引き、年齢制限の抜け穴対策がかえって害になると論じる。

10. [大阪ガス、2030年代に原油を使わないナフサ生産へ](https://www.nikkei.com/article/DGXZQOUF030WW0T00C26A7000000/) (はてブ・会員限定)<br>
    都市ガス生産の技術を応用し、原油由来並みのコストを狙う。日本はナフサの6割を輸入に頼る。
