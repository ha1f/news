コアウィーブ株が16日に終値で12%安、AI データセンター銘柄の間で「借金頼みか、手元資金が厚いか」の選別が進む。一方で Apple は Mac Studio 4台でほぼ1兆パラメータのモデルを動かす手法を公開し、Claude Code チームはエージェント時代のコードレビューを語った。AI の足元は、資金繰りと運用の現場に移っている。

1. [コアウィーブ株12%安、AI 銘柄に選別の波](https://www.nikkei.com/article/DGXZQOGN15CHT0V11C26A0000000/) (日経・会員限定)<br>
   16日の米市場では一時14%安。巨額投資を借入に頼る新興と、資金の厚い巨大テックで売られ方に差が出た。

2. [折りたたみスマホ、26年度は76万台へ　Apple 参入が追い風](https://www.nikkei.com/article/DGXZQOUC15ASG0V11C26A0000000/) (日経・会員限定)<br>
   MM総研の推計で前年度比2.3倍。国内で低迷が続いた市場に、23日の Apple 参入がどう効くか。

3. [Apple、Mac Studio 4台で Meta の Muse Spark Open を動かす](https://machinelearning.apple.com/research/mlx-distributed-inference) (HN・英語)<br>
   続報（10/16掲載）。MLX と Thunderbolt 経由の RDMA で、毎秒36トークン超を出した構成の解説。

4. [Claude Code チームのコードレビュー運用](https://claude.dev/blog/solving-code-review-at-anthropic/) (HN・英語)<br>
   6〜9月にマージ数が2倍超、差し戻し率は4割超減った。読む作業を機械に寄せた設計が書かれている。

5. [OpenRouter、AI エージェントの危険操作を別 AI で止める「Armor」](https://gigazine.net/news/20261016-openrouter-armor/) (GIGAZINE)<br>
   エージェントがツールを実行する前に別モデルが検査し、ルール違反をブロックする。現状はベータ版。

6. [Windows 11 で AI エージェントを隔離する MXC が正式版に](https://www.publickey1.jp/blog/26/windowsaimicrosoft_execution_containersmxc.html) (Publickey)<br>
   Microsoft の隔離環境で、ファイルやネットワークなど境界の範囲を利用側が調整できる。

7. [Claude Code 任せの個人開発で、設計判断を64本の ADR に残す](https://zenn.dev/kam_labz/articles/ebbing-adr-with-claude-code) (Zenn)<br>
   Swift をほぼ書かない開発者が、4か月半で積んだ ADR の書き方と、その効用を語る。

8. [GPS 座標をサーバーに送らない位置情報アプリの設計](https://zenn.dev/kojiokazawa/articles/55fda16d5909be) (Zenn)<br>
   日記アプリ「まいすた」が座標でなく「出来事」を送る方式を採った理由と、妥協した点。

9. [Uber、サービス間の依存を本番指標から自動分類](https://www.infoq.com/news/2026/10/uber-automated-dependency/) (InfoQ・英語)<br>
   RPC ミドルウェアの指標を使い、障害時に止まる依存か否かを fail-close / fail-open に仕分ける。

10. [Claude が NIST 楕円曲線の seed の由来を解明](https://www.anthropic.com/research/ecdsa-curve-origins) (HN・英語)<br>
   NSA が根拠なく示した ECDSA のシード値は「タイムスタンプ」由来だった。Anthropic は実務上の対応は不要としている。

11. [網膜移植と眼鏡型カメラで加齢黄斑変性の視力を回復する PRIMA](https://www.technologyreview.com/2026/10/16/1145840/prima-implant-restores-sight-macular-degeneration-patients/) (MIT TR・英語/一部会員限定)<br>
   欧州で7月に承認され、米国は FDA の判断待ち。対象は世界で500万人超の患者。
