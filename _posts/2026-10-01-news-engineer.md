Google が新モデル「Gemini 4 Argon」を発表。コーディングとサイバー防御を前面に出した。足元では EDG の C++ フロントエンドが30年を経てオープンソース化され、Vite+ 1.0 や WSL Containers も正式版に到達。一方で Reddit は AI ボット対策として RSS を終了する。

1. [Google、Gemini 4 Argon を発表](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-argon/) (HN・英語)<br>
   ソフトウェア開発、法務・金融の業務、サイバー防御向けの最上位モデルで、提供は順次。

2. [Reddit、RSS と公開 API を終了へ](https://techcrunch.com/2026/09/30/reddit-is-killing-rss-feeds-ending-public-api-access-because-of-ai-bots/) (TechCrunch・英語)<br>
   RSS が大規模スクレイピングの入口になっているとして、AI ボット対策で閉じる。

3. [C++ の EDG フロントエンドがオープンソース化](https://edgcpp.org/#transition) (HN・英語)<br>
   30年にわたり各社コンパイラを支えてきた商用エンジンが9月30日に公開され、C++ Alliance が引き継ぐ。

4. [Pi が MCP に対応、方針を転換](https://earendil.com/posts/you-said-no-mcp/) (HN・英語)<br>
   「MCP は載せない」と公言していた AI エージェント Pi の開発元が、考えを変えた理由と Codemode を説明する。

5. [VoidZero が「Vite+ 1.0」を公開](https://www.publickey1.jp/blog/26/javascriptvite_10.html) (Publickey)<br>
   `vp` コマンド1つで Node.js ランタイム、パッケージ管理、ビルドやテストまで扱える MIT ライセンスのツールチェーン。

6. [Microsoft、「WSL Containers」を正式リリース](https://www.publickey1.jp/blog/26/windowslinuxwsl_containersapi.html) (Publickey)<br>
   Docker などを入れずに Windows で Linux コンテナを動かせ、`wslc` コマンドと API を備える。

7. [Netlify、Edge Functions を V8 isolate から Firecracker へ](https://www.netlify.com/blog/edge-functions-firecracker-microvms/) (HN・英語)<br>
   1日約10億回実行される基盤をマイクロ VM に作り直し、5倍の高速化を実現した経緯。

8. [CodeScene、エージェントで C 30万行をリファクタ](https://www.infoq.com/news/2026/09/agentic-refactoring-case-study/) (InfoQ・英語)<br>
   3週間・約4000ドル分のトークンで実施した事例と、検証範囲への実務者の疑問。

9. [テスト35件が全部通ったのに本番コードに触れていなかった](https://zenn.dev/dhubplus/articles/tests-that-verify-nothing) (Zenn)<br>
   iOS アプリの個人開発で、モックが検証を空洞にした3つの実例を出力付きで示す。

10. [青銅器時代の崩壊は何が決定打だったのか](https://www.worksinprogress.news/p/why-really-caused-the-bronze-age) (HN・英語)<br>
