SaaS のカナリーが、PRD からデザインシステムに沿った UI までを Claude Code で生成する仕組みを公開。HTML には JS なしでダイアログを開閉できる属性が加わり、Servo も CSS 対応を広げた。画像生成では OpenAI の新版と、2人のラボが約2万ドルで作ったモデルが並ぶ一日。

1. [カナリー、PRD から UI 生成までを Claude Code で自動化](https://cocoda.design/mayuge33/p/p044da4c62735) (はてブ)<br>
   生成とレビューを別のエージェントに分け、自社デザインシステム「NestUI」を両者の共通の参照に置く構成

2. [2026年版、知っておきたい HTML の新機能](https://zenn.dev/socialplus/articles/50221eafb8a55a) (はてブ)<br>
   Popover API に加え、commandfor と command 属性でダイアログを JS なしで開閉する書き方も紹介

3. [Servo 0.7.0、progress 要素や CSS の alpha() 関数に対応](https://servo.org/blog/2026/11/05/september-in-servo/) (HN・英語)<br>
   埋め込み向けブラウザエンジン Servo の9月分は527コミット。font-width や user-select も新たに使える

4. [Instagram の動画編集アプリ Edits、Mac 版が登場](https://techcrunch.com/2026/11/05/instagram-brings-edits-to-desktop-to-take-on-capcut/) (TechCrunch・英語)<br>
   マルチトラックのタイムラインやキーフレームを備え、他の編集ソフトのショートカット設定も取り込める

5. [OpenAI の画像生成「Images 2.6」、スケッチから GIF も](https://gigazine.net/news/20261105-openai-image-2-6/) (GIGAZINE)<br>
   API では軽量の Flare と精度重視の Sunburst を選べ、直したい箇所をマーキングで指示できる

6. [2人のラボ Linum、約2万ドルで画像生成モデルを学習](https://www.linum.ai/field-notes/pjit-21k) (HN・英語)<br>
   20億パラメータの重みを Apache 2.0 で公開。本来の目標はアニメーション制作向けの動画モデル

7. [言語モデルに筆を持たせる「AI書道コンクール」](https://gigazine.net/news/20261105-ai-shodo/) (GIGAZINE)<br>
   完成画像ではなく筆の置き方や運びをデータで出させ、「やきいも」や絵文字のお題で各モデルを比べる

8. [mixi2、X の過去ポストを取り込めるように](https://zenn.dev/mixi/articles/bcf2363e83b0a2) (Zenn)<br>
   取り込んだ投稿は、投稿の多い日ほど濃いオレンジになるカレンダーで日付ごとに振り返れる

9. [嘘をつく容疑者を問い詰める推理ゲーム「Uncracked City」](https://uncracked.city) (HN・英語)<br>
   実在の街を舞台に、6言語の音声か文字で容疑者に質問し、手がかりと証言の矛盾を突く。報告は3回まで
