Meta が 816B パラメータのオープンウェイトモデルを公開し、Mac Studio 2台で動かせると打ち出した。リーナス・トーバルズは Linux カーネルの改修に Claude Code を使い始め、AI がコードを書く側の中心に入りつつある。一方、広告経由のスパイウェア感染や Starlink の速度制限など、基盤の脆さを突く話題も並んだ。

1. [Meta、オープンウェイトの「Muse Spark Open」公開](https://research.meta.ai/blog/muse-spark-open) (HN・英語)<br>
   総パラメータ816B（稼働42B）、コンテキスト100万トークンで、Apple M5 Ultra の Mac Studio 2台で手元実行できるという。

2. [トーバルズ氏、Claude Code で Linux カーネルを改修中](https://gigazine.net/news/20261016-linus-torvalds-claude-code/) (GIGAZINE)<br>
   公開ブランチ名「noref-filemap-read-with-llm」から AI 支援の開発が見つかり、Phoronix が報じた。

3. [Bun 1.4.3、Go 製 TypeScript 7 の3倍速い型チェッカーを内蔵](https://www.publickey1.jp/blog/26/anthropicbuntypescript_73typescriptbun143.html) (Publickey)<br>
   `bun check` は適合性テストに全件通り、メモリ消費は TypeScript 7 の2分の1〜4分の1とされる。

4. [Google、論文の誤りを AI で見つける「Deep Review」を一般公開](https://gigazine.net/news/20261015-google-deep-review/) (GIGAZINE)<br>
   論理の矛盾や数式のミスを指摘する仕組みで、法律文書や財務資料にも使え、無料枠は週2回。

5. [ニューラルネットは「もともと整っている」という仮説](https://already-clean.goodfire.com/) (HN・英語)<br>
   Goodfire の研究者が、ニューロンが複数の意味を持つ理由は従来の説明と違うと論じる、約65分の長文エッセイ。

6. [広告から感染するスパイウェア「AdFection」、Al Jazeera で確認](https://citizenlab.ca/research/how-discover-tech-turned-targeted-ads-into-a-pipeline-for-spyware/) (HN・英語)<br>
   Citizen Lab が、広告配信業者 Discover-Tech の標的広告を経路に Candiru のスパイウェアが入った事例を技術的に示した。

7. [Microsoft と警察庁、日本向け詐欺メッセージの供給市場を解体](https://gigazine.net/news/20261015-microsoft-japan-took-down-cybercrime-network/) (GIGAZINE)<br>
   「荷物をお届けできません」型の詐欺SMSを支える、攻撃ツールの売買網が対象になった。

8. [ウクライナで Starlink が突然速度制限、迎撃ドローンに影響](https://gigazine.net/news/20261015-starlink-access-restricted-in-ukraine/) (GIGAZINE)<br>
   10月14日に発生し原因は不明のまま。マスク氏は軍用版 Starshield の最終判断はトランプ大統領にあると述べた。

9. [ナルコレプシー患者の脳は意外に若い、認知症研究の糸口に](https://gigazine.net/news/20261015-narcolepsy-youthful-brains-dementia-sleep/) (GIGAZINE)<br>
   強い日中の眠気を抱える人の脳の若さが、睡眠と認知症の関係を探る手がかりになりうると研究者は見ている。

10. [Fortran 誕生70年、ケンブリッジ大の研究所が記念イベント](https://fortran-lang.org/news/2026/09-15-Fortran-birthday/) (HN・英語)<br>
    最初のマニュアルから70年で、気候予測や原子力の計算を支え続けた言語。12月1日にマンチェスターで催される。
