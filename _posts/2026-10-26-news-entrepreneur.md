テック大手7社を除いた米大企業では、AI の利益への貢献は「ゼロ」。Apollo のチーフエコノミストがそう断じた週末に、OpenAI と Anthropic はモデル価格を最大8割下げていた。知能は安くなる一方で、売上に変える力が問われている。ARR の水増しを戒める VC の声に、MRR を照合するツールも並ぶ。

1. [Apollo のエコノミスト「AI は大半の企業に利益ゼロ」](https://techcrunch.com/2026/10/25/ai-delivers-zero-financial-payoff-to-most-companies-according-to-apollo-economist/) (TechCrunch・英語)<br>
   Torsten Slok 氏はテック大手7社を除く「S&P 493」を分析し、利益率も従業員1人あたり売上も横ばいだと指摘

2. [OpenAI と Anthropic、数カ月で LLM を最大80%値下げした理由](https://minimaxir.com/2026/10/cheap-llms/) (HN・英語)<br>
   6月以降の新モデルの価格を時系列で並べ、7月末に GPT-5.6 Luna を8割下げた経緯から「トークンの本当の原価」を考える

3. [日販の Anthropic 向け書籍販売、再販契約で出版社と食い違い](https://www.nikkei.com/article/DGXZQOUC1391P0T11C26A0000000/) (日経・会員限定)<br>
   出版取次大手の日販GHDが2024年12月から1年ほど続けた大量販売で、海外事業者が再販契約の対象になるかが争点

4. [VC と Superhuman 創業者が語る、PMF の危険信号](https://techcrunch.com/2026/10/23/vcs-superhuman-mail-founder-share-red-flags-about-product-market-fit/) (TechCrunch・英語)<br>
   Iconiq の Bharadwaj 氏は、試験導入より本番移行が難関で、ARR とランレートを混ぜた売上説明は見抜かれると話す

5. [Stripe と ChartMogul の MRR のずれを顧客単位で突き止める「MRRaudit」](https://www.producthunt.com/products/mrraudit) (PH・英語)<br>
   差額を原因ごとにまとめ、元の請求書やサブスクのイベントまで遡れる。ChartMogul を使っていなくても Stripe 単体で監査できる

6. [M&A や資金調達向けデータルーム「Papermark」、AI エージェントが運用](https://www.producthunt.com/products/papermark-2) (PH・英語)<br>
   DocSend の代替をうたう文書共有サービスで、ページ単位の閲覧分析を持ち、ISO 27001 と SOC 2 Type II を取得済み

7. [エッジAI の TAI、12.7億円調達で独自チップ量産へ](https://www.nikkei.com/article/DGXZQOUC228EQ0S6A021C2000000/) (日経・会員限定)<br>
   横浜市のトウキョウ アーチザン インテリジェンスが VC の出資とみずほ銀行の融資を組み合わせ、量産は27年秋の見込み

8. [モンゴルの保護区火災、KDDI 子会社に巨額の賠償請求へ](https://www.zakzak.co.jp/article/20261024-HFBYLV7ZKJACBBJK4NY6QF56HI/) (はてブ)<br>
