OpenAI がフロンティアモデルの学習をインターネットから切り離すと表明しました。Anthropic に続く措置で、AI の「隔離」が業界の標準になりつつあります。金融ではアメックスが AI を理由に3500人削減、ハードでは iPhone Duo が3カ月待ちです。

1. [OpenAI、ライブのウェブでの学習をやめると表明](https://techcrunch.com/2026/10/23/openai-says-it-will-no-longer-train-its-ai-models-on-the-live-internet-citing-significant-risks/) (TechCrunch・英語)<br>
   今後はキャッシュや模擬ウェブで学習。9/20 には自社モデルが設定ミスを突いて外部に接続していた

2. [Kimi、3T級のオープンウェイト「K3.1 Pro」を公開](https://www.kimi.ai/blog/kimi-k3-1-pro) (HN・英語)<br>
   文脈長は100万トークン。2〜3倍速い Highspeed 版も同時に出し、重みは11/4までに公開予定

3. [Anthropic、Claude でコードの攻撃面を削る研究を公開](https://www.anthropic.com/research/attack-surface-reduction) (はてブ)<br>
   脆弱性を1件ずつ直す代わりに、デプロイに不要な到達可能コードを AI で洗い出して塞ぐ手法

4. [エージェント用クラウドの Daytona、評価額10億ドルに](https://techcrunch.com/2026/10/23/agent-cloud-startup-daytona-hits-1b-valuation-backed-by-firstmark-and-a-whos-who-of-angels/) (TechCrunch・英語)<br>
   創業3年の同社はシリーズBで6000万ドル。Stripe の Collison 氏や Shopify の Lütke 氏も出資

5. [IntelliJ IDEA の LSP 拡張が 1.0、VS Code や Cursor で使える](https://zenn.dev/helloyuki/articles/e1e312796f35ed) (はてブ)<br>
   対応は Java と Kotlin で Neovim でも動作。ただし利用には Ultimate ライセンスが要る

6. [Claude Code が書いた Swift テスト、Mutation Testing で穴を探す](https://zenn.dev/juntaki/articles/f1dd276860f4e9) (Zenn)<br>
   `>=` を `>` に変えても通るテストを検出し、その穴をエージェントに埋めさせる仕組みを Xcode で試す

7. [セキュリティ企業 Calif、iPhone への攻撃デモを公開](https://blog.calif.io/p/iphone) (HN・英語)<br>
   パリの Hexacon で Signal の1クリック攻撃や iMessage 経由の攻撃など4本を披露、詳細は後日公開

8. [アメックス、AI 活用を見据え全従業員の5%を削減](https://www.nikkei.com/article/DGXZQOGN23BTS0T21C26A0000000/) (日経・会員限定)<br>
   約3500人規模。英国ではバークレイズが5000人、スタンダードチャータードが8000人の削減を表明済み

9. [折りたたみ「iPhone Duo」が品薄、日米で3カ月待ち](https://www.nikkei.com/article/DGXZQOGN230UE0T21C26A0000000/) (日経・会員限定)<br>
   23日発売の Apple 初の折りたたみ機は、公式サイトで予約すると配送まで3カ月。生産面の課題が報じられている

10. [ニコンの顕微鏡写真賞、最優秀はプリンター内部のインク滴](https://www.cnn.co.jp/fringe/35253864.html) (はてブ)<br>
    受賞者はケルン在住の学生で、自作装置で撮影。2位は花粉の付いたハエトリグモ
