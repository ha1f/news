Linux 向けに「Photoshop 風」アプリ PhotoCraft が登場し、イラストアプリ ibisPaint の開発元は Word・Excel・PowerPoint を編集できる無料オフィススイートを公開した。デザインツールの OSS 化が一気に進む一方、日俳連は声優の声の AI 利用に事前同意を求める指針を出し、創作とAIの線引きも動く。ふりがな入りフォントや CSS で色を変える図表ライブラリなど、手元で試せる小さな道具も並ぶ。

1. [Linux に Photoshop 風アプリ「PhotoCraft」、AI で作った OSS](https://japan.zdnet.com/article/35253562/) (はてブ)<br>
   開発チーム GetArtCraft は、Illustrator や Premiere などの代替も同じプロジェクトで進めている。

2. [ibisPaint の開発元、無料の Office 互換スイート公開](https://gigazine.net/news/20261017-ibisOffice/) (GIGAZINE)<br>
   Rust 製で、デスクトップ版は Windows と Mac、Web 版は Wasm と WebGPU で動く。

3. [漢字にふりがなを重ねる日本語フォント「Furifont」](https://gihyo.jp/article/2026/10/furifont) (はてブ)<br>
   源ノ角ゴシックなどを元に、読みを合字として埋め込んだ普通のフォント。プラグインなしで表示できる。

4. [Mermaid 図を CSS 変数で着色できる SVG に変換する「Pele」](https://pele.run/) (HN・英語)<br>
   Mermaid.js より描画が速く、バンドルも 230 kB と小さいと自ら比較表で示す。

5. [写真数枚から Gaussian Splat を作る、ブラウザ完結のデモ](https://antoinemopa.github.io/splatting-rs/) (HN・英語)<br>
   6〜12 枚の写真を読み込むと、ブラウザ内で学習して 3D 表示する。モデルは約 137 MB。

6. [亡くなった声優の声、AI での再現は原則禁止に](https://japan.cnet.com/article/35253656/) (はてブ)<br>
   日俳連の新指針は、学習・生成・作品利用の各段階で書面同意を求め、同意の期間は原則最長1年とする。

7. [AI 登場前に描いた16通りの作風で、絵描きが腕を示す](https://togetter.com/li/2759529) (はてブ)<br>
   「しかるねこ」作者が2017年に、サーバルちゃんを16の画風で模写・アレンジした作品を再び紹介。

8. [ポートフォリオを Void で作り直した記録](https://zenn.dev/nkzn/articles/my-first-void) (Zenn)<br>
   Next.js、Expo Router、Astro と三度作り替えた筆者が、Cloudflare の発表を機に Void へ移った経緯を整理する。
