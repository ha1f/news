テック大手7社を除く米企業で、AI の利益貢献は「ゼロ」。Apollo のチーフエコノミストがそう断じる一方、半導体市場は AI 需要で2027年に約300兆円へ膨らむ見通しです。モデル価格の急落、10年前の CNN に負ける最新 LLM、選挙で割れる AI の推薦先と、AI の「実力と値札」を問い直す話題が並ぶ月曜日。

1. [AI の利益貢献はテック以外でゼロ、Apollo の経済学者](https://techcrunch.com/2026/10/25/ai-delivers-zero-financial-payoff-to-most-companies-according-to-apollo-economist/) (TechCrunch・英語)<br>
   Torsten Slok 氏の分析では、大手7社を除いた「S&P 493」の利益率も1人当たり売上も横ばいのまま

2. [半導体スーパーサイクル、AI 需要で300兆円市場へ](https://www.nikkei.com/article/DGXZQOUB169N60W6A011C2000000/) (日経・会員限定)<br>
   市場規模は2027年に約300兆円に届く見通しで、汎用品の需給が締まりパソコン価格の高騰にも波及

3. [OpenAI と Anthropic、数カ月で LLM を最大8割値下げ](https://minimaxir.com/2026/10/cheap-llms/) (HN・英語)<br>
   Max Woolf 氏が6月以降の両社の発表を価格表で並べ、GPT-5.6 Luna の80%値下げの背景を考える

4. [10年前の CNN が皮膚がん診断で最新 LLM に勝つ](https://lynchlab.net/llm-skin-cancer) (HN・英語)<br>
   皮膚科医が生検済みの200病変で比較、Inception v3 の正答62%に対し GPT-6 Astra と Claude Fable 5.1 は42%

5. [Grok は共和党、GPT は民主党を推す　約500の選挙で調査](https://techcrunch.com/2026/10/24/forced-to-pick-groks-ai-model-chooses-republicans-openais-picks-democrats/) (TechCrunch・英語)<br>
   コーネル大の Parikh 教授らが API に1人を指名させると、Grok 4.7 は92%、GPT-6.1 Sol は97%が片方の党に偏った

6. [Claude Code 生みの親「もうプロンプトは書かない」](https://www.itmedia.co.jp/business/articles/2610/24/news009.html) (はてブ)<br>
   Anthropic のボリス・チェルニー氏は今年コードを1行も書かず、スマホで1日数十本の PR を承認しているという

7. [Cloudflare、TypeScript を Rust に移植した「tsrs」](https://www.publickey1.jp/blog/26/cloudflaretypescriptrusttsrstypescript_7708lsptypescript.html) (Publickey)<br>
   買収した VoidZero も開発に参加。TypeScript 7 比で8倍速・メモリ最大7割減で、今後 LSP にも対応予定

8. [TiDB の PingCAP に侵入、ソースコードと顧客データが流出](https://www.infoq.com/news/2026/10/pingcap-cloud-data-breach/) (InfoQ・英語)<br>
   恐喝集団 FulcrumSec が10.6TB を盗んだと主張し、TiDB Cloud の制御プレーンの記録も含まれるという

9. [GMO への攻撃者、利用者 PC の乗っ取りを予告](https://www.nikkei.com/article/DGXZQOUC250PP0V21C26A0000000/) (はてブ・会員限定)<br>
   続報（10/25掲載）。攻撃者は27日正午を身代金の期限に設定し、PC 内の個人情報の拡散もほのめかしている

10. [税抜と税を別々に切り捨てたら、請求の9割で1円不足](https://zenn.dev/shinsei99/articles/rounded-the-parts-not-the-whole) (Zenn)<br>
   水道光熱費を各戸に配分する Swift アプリで、「端数は最後に1回」と決めていたのに1円ずれた事例

11. [ドローン、1人で10台超の同時運航が可能に](https://www.nikkei.com/article/DGXZQOUD056M20V00C26A6000000/) (日経・会員限定)<br>
   国交省が1人5機までの上限を撤廃。物流やインフラ点検、測量での活用と人手不足の解消を見込む
