AI 株の急落で、Anthropic の IPO に評価額引き下げや延期の観測。主幹事の Goldman Sachs は社内で Claude Code の利用を絞り込んだ。VC の Sequoia は内紛報道、国内では newmo が208億円を集め、資金の流れが改めて問われる週明け。

1. [Anthropic の IPO、AI 株急落で評価額に暗雲](https://www.nikkei.com/article/DGXZQOFL06C7P0W6A101C2000000/) (日経・会員限定)<br>
   続報（11/7掲載）。公開価格の引き下げや上場延期の観測が市場に出始め、中間選挙での民主党躍進も重なる

2. [Goldman Sachs、Claude Code をトレーダーと銀行員から取り上げ](https://www.thestateofai.com/news/goldman-sachs-claude-code-traders-bankers) (HN・英語)<br>
   10月の社内指針で利用をエンジニアに限定。同行は Anthropic の IPO で主幹事を務める立場でもある

3. [Sequoia の改革、前トップ Botha 氏の遺産を消す動きと FT が報道](https://techcrunch.com/2026/11/08/sequoia-partners-reportedly-blindsided-when-roelof-botha-joined-spacex-board/) (TechCrunch・英語)<br>
   続報（11/8掲載）。Botha 氏が社内承認なしに SpaceX の取締役に就き、パートナー陣が反発したとされる

4. [元シークレットサービスの VC、2本目の2.5億ドル規模ファンドへ](https://techcrunch.com/2026/11/08/the-ex-secret-service-agent-who-flipped-a-hacker-is-now-raising-a-second-250m-cybersecurity-fund/) (TechCrunch・英語)<br>
