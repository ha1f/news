Tavus の映像AI「Griffin」が、1分のビデオ通話で参加者の約48％に人間と誤認された。Meta は AI エージェント「Muse」を自作ガジェットに載せる SDK を公開し、VS Code には複数モデルを使い分ける HydraFusion が入った。AI が画面の向こうと手元の道具の両方に入り込み、デザインの前提も動き始めている。

1. [Tavusの映像AI「Griffin」、通話相手の約半数が人間と誤認](https://gigazine.net/news/20261006-tavus-griffin/) (GIGAZINE)<br>
   研究プレビュー版の実験で、通話した54人のうち26人が相手を実在の人間と答えた。

2. [MetaがAIエージェント「Muse」搭載ガジェットの自作キットを公開](https://gigazine.net/news/20261007-muse-gadgets/) (GIGAZINE)<br>
   ESP32 ボードや Raspberry Pi 5 に載せ、ボタンやセンサーをつないで独自の道具に仕立てられる。

3. [企業向けAIの信頼を左右するUX判断5つ](https://dribbble.com/stories/2026/08/31/cl-flexy-global-enterprise-ai-solutions) (Dribbble・英語)<br>
   MIT 調査で企業の生成AI試行の約95％が成果を出せなかった点を出発点に、コンプライアンスや銀行業務での設計経験から整理する。

4. [Pinterest、ヘア・ネイルのピンを「施術プラン」に変換](https://techcrunch.com/2026/10/06/pinterests-ai-now-turns-beauty-pins-into-action-plans/) (TechCrunch・英語)<br>
   画像を眺めるだけの体験から、美容室で伝える用語と費用・所要時間の見積もりまで届ける新機能。

5. [説明スキル比較：ELI5・Archify・Explainer](https://blog.lai.so/eli5-archify-explainer-skills/) (はてブ)<br>
   絵本風の ELI5 や図で関係を探索する Archify など3種に同じ題材を説明させ、出力の違いを見比べる。

6. [Claude Code の拡張「Claude Mods」を3つ試した記録](https://zenn.dev/yoshihiko555/articles/ea2db6070058b3) (Zenn)<br>
   入力欄の Markdown に色を付ける mod などを実際に入れ、画面まで触れる拡張の勘所と安全な入れ方を書く。

7. [LibreOffice、「AIを入れない」を機能として打ち出す](https://techcrunch.com/2026/10/06/libreoffice-says-no-ai-is-now-a-software-feature/) (TechCrunch・英語)<br>
   開発元は、プライバシーを理由に既定設定へ AI を組み込む予定はないと表明した。

8. [VS Codeに複数AIモデルを使い分ける「HydraFusion」](https://www.publickey1.jp/blog/26/vs_codeaiaihydrafusion.html) (Publickey)<br>
   Microsoft の研究プロジェクトで、1.140 でリサーチプレビューとして実装された。推論やデバッグなど作業ごとに最適なモデルを選ぶ。

9. [Linux向けメール・カレンダー「Penguin Mail」1.0](https://penguin-mail.com/) (HN・英語)<br>
   Gmail や Microsoft、IMAP の各アカウントを一つの受信箱に集約し、ライト・ダーク表示にも追従する GPL のソフト。
