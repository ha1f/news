Google が AI エージェントに画面を返させるプロトコル「A2UI」を1.0に。エージェント向けの UI 部品やアニメーション素材も次々に出てきた。一方で、AI で作ったアプリ15万件超を調べた報告は、作り手が見落とす「見えない部分」の危うさを突きつける。

1. [Google、エージェントが UI を返すプロトコル「A2UI」1.0](https://gihyo.jp/article/2026/11/a2ui-1.0) (はてブ)<br>
   1.0でエージェントと描画側が互いの関数を呼べるようになり、Web・iOS・TV まで同じ記述で描ける

2. [AI アプリ向けの React 部品集「Kokonut UI」](https://www.producthunt.com/products/kokonutui) (PH・英語)<br>
   Tailwind CSS・Motion・shadcn/ui の上に作られた無料の OSS で、モデル選択などの部品がコマンド1つで入る

3. [組み込める Rive アニメのテンプレート集「Hoverine」](https://www.producthunt.com/products/hoverine) (PH・英語)<br>
   インタラクティブなアニメーションを作る Rive の素材で、色・文字・画像を変えて商用ライセンス付きで書き出せる

4. [PyPI、セキュリティ情報が分かるプロジェクトページに刷新](https://blog.pypi.org/posts/2026-11-06-ui-updates-complete/) (HN・英語)<br>
   Python の公式パッケージ置き場が、利用者調査とデザイン会社 Kabu Creative との協業で専用タブを新設した

5. [AI アプリ生成の Lovable、作られたアプリから旅券情報や私信20万件が丸見え](https://www.crissyfield.de/research/lovable-en/) (HN・英語)<br>
   独 Crissy Field 社が Lovable 製の15万9041件を調べ、ログインなしで読める個人情報を多数見つけた

6. [「この余白を2mmに」で直るチラシ、Claude Code で入稿まで](https://qiita.com/nttdata-ccs-techblog/items/71f81eba6a4bcf4de1df) (Qiita)<br>
   NTTデータCCS のデザイナーが、Illustrator を MCP 経由で AI に触らせ、数値指示で直す手順を記録

7. [Google Labs、AI がグループ用の共有スペースを作る「Tabletop」](https://gigazine.net/news/20261113-google-tabletop/) (GIGAZINE)<br>
   リンクやファイルを置いて頼むと、旅行やサークル向けに全員で同時編集できる道具を即席で組み立てる実験版

8. [Slack のメッセージで Markdown の表が描画されるように](https://zenn.dev/lnest_knowledge/articles/ed5977bd7b6c1f) (Zenn)<br>
   パイプ区切りの表を貼ると左・中央・右寄せまで反映、11/11時点に macOS 版とブラウザ版で確かめた記録

9. [Switch 2 版『時のオカリナ』、ジャンプボタンを足すかで議論](https://gigazine.net/news/20261113-nintendo-how-made-zelda-ocarina-of-time/) (GIGAZINE)<br>
   青沼英二氏と藤林秀麿氏が、原作の体験を残す部分と変える部分の線引きを GameSpot に語った
