Google の動画生成「Gemini Omni 1.2 Flash」が15秒の尺に対応し、ElevenLabs は AI で作った曲を SoundCloud へ直接出せるようにした。作る道具が AI に寄っていく一方で、Dribbble ではデザイナーが実装まで抱える「デザインエンジニア」という働き方が語られる。iPhone Duo 対応アプリは10万本の大台に。

1. [Google、15秒の動画を作れる「Gemini Omni 1.2 Flash」](https://blog.google/innovation-and-ai/technology/developers-tools/introducing-gemini-omni-1-2-flash/) (HN・英語)<br>
   会話を重ねてクリップを直せるようになり、Gemini API と Google Vids で今日から使える

2. [ElevenLabs、AI で作った曲を SoundCloud へ直接公開可能に](https://techcrunch.com/2026/11/05/elevenlabs-now-lets-users-publish-ai-generated-music-directly-on-soundcloud/) (TechCrunch・英語)<br>
   SoundCloud の Artist Pro 会員には、月1000曲まで作れる ElevenMusic Pro を3カ月つける

3. [Claude Code が Premiere Pro を290回操作、53分のポッドキャストを編集](https://zenn.dev/salt2/articles/2b6e403e059b10) (Zenn)<br>
   MCP を使わず自作の CEP 拡張に JSX を送る構成で、人が触ったのは色の数値だけ

4. [モックアップの先へ、スタジオ Joyce がデザインエンジニアになった理由](https://dribbble.com/stories/2026/11/06/why-we-became-design-engineers) (Dribbble・英語)<br>
   設計と実装を同じ人が担い、動く試作の使われ方を見て磨く進め方を CEO が語る

5. [Apple、iPhone Duo 向けに最適化したアプリが10万本を突破](https://techcrunch.com/2026/11/06/the-duo-apps-are-coming-says-apple/) (TechCrunch・英語)<br>
   Word や Zoom、カメラの Halide Mark III が新たに対応。未対応アプリは画面横に黒帯が残る

6. [新 MacBook Pro で10年ぶりに光る Apple ロゴ、消灯もできる](https://gigazine.net/news/20261107-apple-how-turn-off-macbook-glowing-logo/) (GIGAZINE)<br>

7. [Pixar『トイ・ストーリー』を支えた RenderMan のシェーダー](https://codeaihq.com/computer-generated-asset-pipelines-shading-language-in-toy-story-1995/) (HN・英語)<br>
