Microsoft が次世代 AI チップ「Maia 300」を発表、Maia 200 からわずか約9カ月での更新だ。Meta は新モデル「Muse Wonder」を投入し、Spotify ではコード変更数が1年で倍増。AI を作る側も使う側も、速度に品質管理が追いつくかが問われている。

1. [Microsoft、AI チップ「Maia 300」を発表](https://pc.watch.impress.co.jp/docs/news/2147412.html) (はてブ)<br>
   TSMC 2nm 製のチップレット構成で、288GB の HBM4 を載せ、1ラック96基まで拡張でき、2027年から自社 DC に順次導入される。

2. [Meta、エージェント向け新モデル「Muse Wonder」](https://research.meta.ai/blog/muse-wonder) (HN・英語)<br>
   利用者の関心事を覚え続ける Active Memory と Active Focus を軸に、Meta Model API と Muse Code から使える。

3. [Spotify、AI でコード変更が月8100件から1.7万件に](https://www.infoq.com/news/2026/10/spotify-ai-quality-controls/) (InfoQ・英語)<br>
   約3000の本番サービスを抱える同社が、変更量の増加を受けてテスト・監視・ロールバック体制をどう見直したかの報告。

4. [AI の性能がリリース後に落ちたかを測る「Nerf Bench」](https://gigazine.net/news/20261013-nerf-bench/) (GIGAZINE)<br>
   BridgeBench が、公開日の性能を100%として現在値を比べ、90〜110%を通常の揺らぎとみなす仕組み。

5. [OpenCode から軽量な Pi へ、CLI ハーネスを乗り換え](https://voluntas.ghost.io/migrate-opencode-to-pi/) (はてブ)<br>
   OpenCode v2 のデーモン常駐や多機能化を重く感じた筆者が、プラグイン無しではほぼ素の Pi を選んだ理由。

6. [サイボウズの Mythos 対策「Logos」プロジェクト](https://blog.cybozu.io/entry/logos-overview) (はてブ)<br>
   リポジトリを丸ごと渡す検証では誤検出ばかりだったため、セキュリティスキャン用ハーネスを自作するに至った経緯。

7. [評価スクリプトだけが4か月前のモデルを見ていた](https://zenn.dev/kiribako_dev/articles/eval-pipeline-stale-detector) (Zenn)<br>
   釣果記録アプリの魚種分類器で、オフライン評価と実機の結果が食い違った原因を、外れた仮説4つとともに追う。

8. [Intel の命令表にある vfmaddrnd231pd は実在するのか](https://purplesyringa.moe/blog/who-is-vfmaddrnd231pd/) (HN・英語)<br>
   命令ごとに丸めを指定できるはずの FMA 命令が、アセンブラにもコンパイラにも存在しないと突き止める調査。

9. [AI の請求額は信用できない、QCon AI での講演](https://www.infoq.com/presentations/ai-cloud-cost-economics/) (InfoQ・英語)<br>
   CloudZero の CTO が、AI 支出がクラウド費用を上回る現状と、トークン消費を競う風潮の問題点を語る50分。

10. [産業革命期、精度の高い「ねじ」はどう作られたか](https://gigazine.net/news/20261013-how-machines-learned-precision/) (GIGAZINE)<br>
    ウィルキンソンの中ぐり盤からモーズリーのねじ切り旋盤まで、工作機械の精度が段階的に上がった道筋。
