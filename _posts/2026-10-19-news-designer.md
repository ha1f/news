Linear の共同創業者 Karri Saarinen が「ソフトウェアには作り手の顔が要る」と書き、AI で開発工程を自動化する流れに疑問を投げた。きょうは UI の背後にある判断や由来を掘る記事が多い。メール送信のエラー文、シーリングファンの奇抜な造形、変体仮名の字形まで、デザインの「なぜ」を追う。

1. [Linear 創業者「ソフトウェアの背後には人がいる」](https://karrisaarinen.com/posts/someone-behind-the-software/) (HN・英語)<br>
   同じ顧客と技術でも別物になる理由を、データより直感を重んじる Linear の流儀から語る。

2. [90年代の Unix メールが返した謎のエラー「Not a typewriter」](https://unsung.aresluna.org/traditional-but-puzzling/) (HN・英語)<br>
   元 Google・Figma の UX デザイナー Marcin Wichary が、sendmail の大文字小文字判定など4つの要因の重なりを解く。

3. [シーリングファンの造形が混沌としている理由](https://gigazine.net/news/20261019-ceiling-fans/) (GIGAZINE)<br>
   建築ブロガーが100種類超を調べ、シャンデリア融合型など、羽根が主役でない製品が増えた事情を指摘する。

4. [国立国語研究所の「変体仮名一覧表」](https://cid.ninjal.ac.jp/kana/list/) (はてブ)<br>
   Unicode のコードポイントと字母を対応づけた表で、あ行だけでも安・惡・愛・阿と字形の由来が並ぶ。

5. [地図から漫画の背景線画を起こす「どこでもロケハン」](https://gigazine.net/news/20261018-dokodemo-rokehan/) (GIGAZINE)<br>
   実在の街並みを3Dにして線画とトーンへ変換する無料ツール。商用利用可だが、人気で地図検索に制限が入った。

6. [インライン編集 UI を使い回せる形で実装する](https://zenn.dev/numa_san/articles/50b847c58f0854) (Zenn)<br>
   編集直後に古い API データが出てしまう問題などを、土台コンポーネントへのロジック集約で片づける実装記録。

7. [iPhone や iPad を Mac の拡張ディスプレイにする「OpenDisplay」](https://gigazine.net/news/20261018-opendisplay/) (GIGAZINE)<br>
   Sidecar や Duet Display の代替で、無料。USB 接続なら最大60FPS、1台の Mac に最大3台をつなげる。

8. [ノート・カンバン・グラフを一本化するメモアプリ「Poznote」](https://gigazine.net/news/20261018-poznote/) (GIGAZINE)<br>
   セルフホストできる OSS で、AI 連携やブラウザ拡張、自動バックアップも備え、情報の種類ごとのアプリ使い分けを減らせる。

9. [ゼルダの伝説の年表を一枚で追えるファンサイト](https://legendofhyrule.com/) (HN・英語)<br>
   『時のオカリナ』以降の子供・大人・敗北の3系統の分岐を、各作品のあらすじとともに時系列で辿れる。
