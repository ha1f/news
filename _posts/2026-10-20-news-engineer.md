国内企業への不正アクセスで、攻撃元のインフラから AI 自律型ペンテストシステム「ARTEX」が見つかった。AI が攻める側に回る現実が、国内の調査で裏づけられた形だ。一方で開発者の足元では、OpenCode の運営元への侵入で API キー流出の疑いが出て、Claude Code の放置会話は 27 万トークンが 1 万強へ自動で縮む。新モデルとサーバレス基盤の発表が続くなか、PS5 や PSP をめぐる遊び心ある実験も並んだ。

1. [国内の不正アクセス、攻撃元は AI 自律型ペンテスト「ARTEX」](https://gmo-cybersecurity.com/blog/20261019/) (はてブ)<br>
   GMO サイバー犯罪対策センターが攻撃元インフラを調べ、前回の「AI の疑い」を使用ツールの特定まで進めた続報。

2. [AI コーディングツール OpenCode、運営元が侵入され API キー流出の恐れ](https://gigazine.net/news/20261019-opencode-leak/) (GIGAZINE)<br>
   10月17日の不正アクセスを受け、身に覚えのない AI 利用料金が発生したという利用者の報告も出ている。

3. [MiniMax が「M3.1 Flash」公開、推論は約3倍速く費用は7割減](https://www.minimax.io/blog/minimax-m31f) (Hacker News・英語)<br>
   匿名で運用されていた試験版「Space Bunny」が実体で、エージェント作業やコーディング、セキュリティ分野を強化したという。

4. [Claude Code を 55 分放置したら会話が 27 万トークンから 1.3 万へ圧縮された](https://zenn.dev/ojisan_ai_lab/articles/claude-code-idle-compaction-20261019) (Zenn)<br>
   v2.1.299 のリリースノートにある「アイドル圧縮」を、再開した会話で実測して公式の記述と突き合わせた記録。

5. [Mistral、時系列予測の基盤モデル「Timestral」を公開](https://mistral.ai/news/timestral/) (Hacker News・英語)<br>
   5M から 209M の 4 サイズで CPU でも動き、最大モデルは主要 3 ベンチマークで首位を名乗る。

6. [AWS Lambda に Next.js や Hono をそのまま載せる「Lambda Web Functions」](https://www.publickey1.jp/blog/26/aws_lambdanextjshononodejsaws_lambda_web_functions.html) (Publickey)<br>
   Express や Fastify を含む Node.js フレームワークのアプリを、Lambda 向けに書き換えず動かせる新機能。

7. [Google の EmbeddingGemma 2、コード・画像・動画・音声まで埋め込みに対応](https://www.infoq.com/news/2026/10/embeddinggemma-2-multimodal/) (InfoQ・英語)<br>
   Gemma 4 ベースで Apache 2.0 ライセンスの小型モデル。端末内で動かす検索や RAG の部品になる。

8. [iOS 27 の Private Cloud Compute に現場写真を読ませる比較検証](https://zenn.dev/dadachi/articles/fieldpic-private-cloud-compute-photos) (Zenn)<br>
   チェックリスト用アプリで所見を書かせ、端末内モデルとの差と、効いたプロンプトの直し方を実機で整理している。

9. [脱獄した PS5 の GPU で llama.cpp を動かす「PS5LM Plus」](https://gigazine.net/news/20261019-ps5lm-plus-gpu-ai/) (GIGAZINE)<br>
   PS5 本体で動かした AI モデルに、PC やスマホのチャットから接続して使える OSS アプリ。

10. [エミュレーター無しでブラウザ上で PSP ゲームを動かす「PSP Web Recomp」](https://gigazine.net/news/20261020-psp-web-recomp/) (GIGAZINE)<br>
    開発者 snuri00 氏が GitHub で公開した、ゲームをブラウザ向けに変換して動かす試み。
