アンソロピックが7〜9月の売上高を前年の12倍と開示し、同じ目論見書で「自己改良 AI」の一歩手前にいると警告した。Marvell の1150億ドル買収、Apple の在庫154%増。AI 需要がチップと部品の値段を押し上げている。

1. [アンソロピック、7〜9月の売上高は前年の12倍](https://www.nikkei.com/article/DGXZQOGN02AJ40S6A101C2000000/) (日経・会員限定)<br>
   続報（10/31掲載）。売上は約169億ドルに達したが、営業損益はなお5億ドルの赤字で、IPO 用の S-1 を更新した

2. [Anthropic、自己改良する AI の一歩手前と目論見書で警告](https://techcrunch.com/2026/11/02/anthropic-warns-that-its-very-close-to-rsi-capability-aka-self-building-ai/) (TechCrunch・英語)<br>
   決算数字の陰で、研究開発に自社 AI を使うことの危うさを S-1 の細則に書き込んでいた

3. [GPT-6 Astra、Qwen の重みを直接書き換えて数学の正答率を6倍に](https://rikiyat.github.io/blog/weight-space-programming/) (HN・英語)<br>
   MIT CSAIL の研究。勾配を使わず重みの0.016%を編集し、MATH-500 を7.9%から48.1%に上げた

4. [NYT など新聞社、Brave を提訴　AI 企業への記事の横流しで](https://techcrunch.com/2026/11/02/new-york-times-and-other-outlets-sue-web-browser-brave-over-alleged-content-scraping/) (TechCrunch・英語)<br>
   300億ページ超の索引を作った正体不明のクローラーと、ペイウォールを越える機能も訴えの対象になった

5. [Uber、800超の MCP サーバーを束ねるゲートウェイを構築](https://www.infoq.com/news/2026/11/uber-mcp-gateway-ai-agents/) (InfoQ・英語)<br>
   社内5000超のツールへのエージェントの接続を、権限管理や機密情報のマスクも含めて一か所で統制する

6. [Tuist で project.pbxproj を Git から外し、コンフリクトをなくす](https://zenn.dev/digitalio/articles/eliminate-pbxproj-conflicts) (Zenn)<br>
   ECナビのアプリチームが、型で定義ミスを防げるかを条件に XcodeGen・Bazel と比べて選んだ経緯

7. [日本の全法令を git の履歴にした「houritsu」](https://zenn.dev/koheiwada/articles/houritsu-japanese-laws-as-git) (はてブ)<br>
   8982法令・2万3338コミット。改正法の施行1本を1コミットにし、どこが変わったかを git diff で追える

8. [Apple の在庫が前年比154%増、メモリ高騰に備えて積み増し](https://techcrunch.com/2026/11/02/apples-inventory-surges-154-as-memory-chip-costs-climb/) (TechCrunch・英語)<br>
   ターナス CEO は12月期もメモリ価格が上がると見込み、粗利率は前期の47.9%から45〜46%に下がる見通し

9. [Marvell、光通信の Lumentum を1150億ドルで買収](https://techcrunch.com/2026/11/02/in-one-of-the-largest-deals-in-tech-history-marvell-buys-lumentum-for-115b/) (TechCrunch・英語)<br>
   MS の Activision 買収（687億ドル）を上回る株式交換で、両社とも3月に Nvidia から20億ドルずつ出資を受けていた

10. [欧州のスーパーで冷蔵設備にサイバー攻撃、食品を大量廃棄](https://www.nikkei.com/article/DGXZQOGN02B1R0S6A101C2000000/) (日経・会員限定)<br>
   ベルギーのデレーズ約40店などで設定が除霜モードに切り替えられた。10月のフランスに続く同じ手口

11. [Evernote、新プランで年額が最大約1.9倍に](https://gigazine.net/news/20261103-evernote-pricing-experiments/) (GIGAZINE)<br>
   Bending Spoons 傘下で Personal を廃止。安い Starter はノート1000件・ノートブック20個までの上限付き

12. [時速113kmで海に突っ込むカツオドリ、首が折れない理由](https://gigazine.net/news/20261103-plunge-diving-seabirds-without-breaking-neck/) (GIGAZINE)<br>
   CT で頸椎を比べると、急降下する鳥の椎骨は短く太い「ずんぐり型」で、首を回す鳥とは形が違った
