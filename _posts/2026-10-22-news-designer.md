Apple が全メニュー項目にアイコンを付ける方針を撤回し、フォルダブルの「iPhone Duo」は発売前から試用レビューが出始めた。Chrome 156 では CSS だけで乱数を扱えるようになり、Anthropic は先回りして動くエージェントアプリ「Claude Duet」を試験公開した。デザインとツールの両面で、作り方の前提が動く一日。

1. [macOS のメニューにアイコンを並べる流儀、Apple 自身が撤回](https://blog.jim-nielsen.com/2026/icons-in-every-menu/) (Hacker News・英語)<br>
   Tahoe で全項目に付けたアイコンを次期 OS で外し、新 HIG も悪例と明記した経緯を、筆者は「実際にやって戻した経験」の重みとして論じる。

2. [Apple 初のフォルダブル「iPhone Duo」、iPad の代用品ではない](https://www.itmedia.co.jp/pcuser/articles/2610/21/news074.html) (ITmedia)<br>
   ヒンジの感触や開閉の「カチリ」まで作り込まれた試用機から、Apple が新ジャンルとして位置づける狙いを読み解く連載。

3. [Chrome 156、CSS だけで乱数が使える](https://gigazine.net/news/20261021-google-chrome-156/) (GIGAZINE)<br>
   ランダム配置の CSS 化に加え、遷移を始めた要素の特定や IndexedDB の SQLite 化など、開発者向けの変更点をまとめている。

4. [Anthropic、先回りして動くエージェントアプリ「Claude Duet」を試験公開](https://claude.com/product/claude-duet) (Hacker News・英語)<br>
   要確認事項を自分から持ってきて、席を外している間も作業を続け、実行前に承認を求める設計で、研究プレビューとして始まった。

5. [「コードは粘土になった」エージェント開発の造形論](https://www.albertodenia.com/writing/code-is-clay-now) (Hacker News・英語)<br>
   変更コストが崩れたコードを彫刻のように大づかみから細部へ整える作り方を、石工と粘土の比喩で説明する。プロダクトデザイン寄りの視点。

6. [デザイン会社10社に学ぶ、受注直後のオンボーディング](https://dribbble.com/stories/2026/10/20/agencies-with-excellent-client-onboarding) (Dribbble・英語)<br>
   ブランディングから UI/UX まで10社が、初期の聞き取りや早い納品物、進捗共有の仕組みで顧客との認識を揃える方法を紹介。

7. [Oxlint + Oxfmt で、モノレポの規約をコードとして強制する](https://zenn.dev/reality_tech/articles/oxc-monorepo-20261006) (Zenn)<br>
   ESLint + Prettier から Biome と Oxc を比べて Oxc 系に移った理由と、規約を機械的に守らせる運用の実例。

8. [DuckDB 2.0.0 LTS が登場、VARIANT 型やトリガーを追加](https://duckdb.org/2026/10/21/announcing-duckdb-200) (Hacker News・英語)<br>
   1.5 から約2万コミットを経た初のメジャー版で、非同期 I/O や拡張可能な SQL パーサも入り、移行時の破壊的変更も整理されている。

9. [モーター1個だけで飛んで曲がるドローンを自作](https://gigazine.net/news/20261021-drone-with-one-motor/) (GIGAZINE)<br>
   3D プリンター製の特殊プロペラと、モーター回転を高速で変える制御で方向転換を実現し、寝室での飛行実験に成功した。
