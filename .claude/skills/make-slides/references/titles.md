# タイトル

タイトルは、そのスライドが答える問いへの答え（主張）を言い切る。トピック名（「売上について」）、作業報告（「アンケートを実施」）、図の解説（「〜がわかる」）にしない（Slideworks、Atkinson、Alley、杉野）。どのモードでも同じで、変わるのは長さと形だけ。投影でも、スライドは写真に撮られたり後で配られたりして、話し手抜きで読まれる。例外は、問いを立てること自体が役割のスライド（導入やセクションの扉の問いかけ）で、これは問いをタイトルにしてよい。

実証の裏付けがあるのは主張の見出しと説明的な図の組み合わせで、見出しだけの効果は切り分けられていない（Garner & Alley 2013 は見出し・図・文字量を同時に変え、文の見出しを試した Alley 2006 も活字や図を同時に変えている）。そのためタイトルは図と一組で決める。

## 決め方

AI が作るタイトルでよく指摘される失敗は、本文で言いたいことを短く圧縮するだけで、どれが一番重要かを決めていないことにある（いる科ほか。事例からの指摘で、検証はされていない）。短くするのは最後にする。字数の目安は警告であって制約ではなく、優先順位は「主張が一つ」＞「主題語と範囲を決める語」＞「図との一致」＞「短さ」。

1. このスライドが答える読み手の問いを 1 つ書く（設計書のタイトル列から）
2. 言いたいことを字数を気にせず書き出す。発表者ノートや台本があれば合わせる
3. 書き出した要素を列挙し、中核メッセージと聞き手に照らして重要な順に並べ、最上位を一つに決める（点数でなくてよい。いる科は 1〜10 の点数を使った）。要素が一つしかなければ省く。この順位は自分の判断なので、作り手の意図とずれていないかは、SKILL.md 手順 3 で設計書をユーザーに見せるときに確かめてもらう
4. 最上位の要素をタイトルにする。何についての主張かを示す語（主題語）を先頭近くに置き、重要度の低い前提を前置きにしない（読み手は最初の数語しか見ないことがある。NN/g、新聞の見出し）。二番手以下は補足行、図、発表者ノート、次のスライドに回す
5. タイトルの述語と図の形が合っているか確かめる（[visuals.md](visuals.md) の F1）
6. 削る: 重複した語、前置き、日本語なら「〜について」「〜のための」「〜による」のような平仮名の言い回しと主張に要らない助詞（前田）。主題語（誰の、どこの、いつの）と、主張の範囲を決める語は削らない
7. 長さを確かめる。日本語は字数をコマンドで数える（`python3 -c 'import sys; print(len(sys.argv[1]))' 'タイトル'`。目で数えると誤る）。英語は、読み物なら語数を数え、投影なら描画した画像で 1 行かを見る。ルールシートの目安を超えたら、タイトル＋補足行の二層にする（前田の 13＋40）。それでも主張が二つ残るならスライドを分ける。文字を小さくして収めない
8. 補足行を置いたら、タイトルとつなげて一文にして読み、同じことを言い換えていないか確かめる（鈴木）

形は完全な文でも、「〜は二極化」のような見出しの形でもよい。判定するのは形ではなく、主張を含むかどうか。

## 例（架空）

社内アンケート（回答者 120 人）で、社員の週あたりの学習時間が「ほぼゼロ」と「5 時間以上」の二つの山に分かれた分布図のスライド。

- 元のタイトル:「学ぶ機会は増えた。でも、差は開いている」
  - 主張が二つあり、低い要素（機会が増えた）が先頭にある
  - 「差」が何の差か読めない
  - 図が示しているのは二つの山なのに、タイトルは「差」としか言っていない
- 順位: 1 学習時間が二極化している ／ 2 二つの層の特徴 ／ 3 学ぶ機会が増えた
- 直したタイトル:「社員の学習時間は二極化」
- 補足行:「社内アンケートで週 5 時間以上の層とほぼゼロの層に分かれた（回答者 120 人）」。これを消すと、調査の種類と母数という限定が画面から消える

## 表紙のタイトル

デッキ全体のタイトルは中核メッセージから作り、何の話か（ネタ）とどの視点で語るか（切り口）が読めるようにする（中嶋）。長くても 40 字以内にする（森重、経験則）。表紙は T1〜T10 の対象外で、T11 で判定する。

## 合格条件

| ID | 条件 | 判定 | 考え方 |
|---|---|---|---|
| T1 | タイトルが主張になっている。トピック名、作業報告、「〜がわかる」、「〜について」、疑問形で終わっていない（問いを立てるスライドは除く） | LLM | 1 |
| T2 | 主張が一つ。「〜。でも、〜」「〜だが、〜」のような対比、句点二つ、「A ではなく B」でつないでいない。候補を見つけたら、本当に一つの主張かを判断する | LLM | 2 |
| T3 | 決め方の手順 3 の最上位の要素がタイトルにあり、主題語が先頭近くにあり、重要度の低い前提が前置きになっていない（順位を省いたスライドは前の二つだけ） | 設計書の順位と照合 | 2 |
| T4 | 「差」「変化」「課題」「本質」「価値」「可能性」のような、何の・誰の・どれだけが読めない語が、主語や述語として単独で使われていない | LLM | 3 |
| T5 | 主張を決める数字が素材にあれば、タイトルか補足行に入っている | LLM | 3 |
| T6 | 長さがルールシートの目安に収まるか、超えた分について手順 7 を踏んでいる。2 行を超えない（字数は目安） | 日本語はコマンド、英語の投影は画像 | 2・4 |
| T7 | 「しつつある」「一部で」「〜の可能性」「〜の印象」のように範囲を決める語をタイトルから外したなら、補足行か注記に残っている | 元の書き出しと照合 | 3・4 |
| T8 | 主題語（誰の、どこの、いつの）を短さのために落としていない | LLM | 3 |
| T9 | 日本語の 1 行のタイトルに読点、句点、感嘆符、疑問符、コロンがない（問いを立てるスライドの疑問符は除く。目安。読点が要るなら主張が二つの疑いがあるので T2 を見直す） | 目視かコマンド | 2 |
| T10 | 補足行、図のキャプション、下部の箱に、タイトルより強い主張がなく、タイトルと同じことの言い換えもない。強い主張があればそれをタイトルにし、元の箇所は消すか補足に書き換える | LLM | 2 |
| T11 | 表紙のタイトルからネタと切り口が読め、40 字以内（字数は目安） | LLM とコマンド | 1 |
