# デッキの構成

構成はソフトを開く前に、文字だけで決める。手順は流派をまたいで一致している（Duarte、Knaflic、Reynolds、Atkinson、Doumont、前田、伊藤、元マッキンゼー社員のブログ）。根拠は規範と経験則で、デッキ構成の効果を測った実証研究は見つかっていない。

## 中核メッセージ

デッキ全体で聞き手に持ち帰ってほしいことを 1 文にする。

- 視点（自分の主張）、懸かっているもの（なぜ聞き手に関係するか）、求める行動の三つを含める（Duarte の Big Idea、Knaflic）
- スライドなしで 1 分で言えるか試す。言えなければ、まだ中身が決まっていない（Knaflic の 3 分ストーリー、伊藤）
- 悪い例:「本資料では市場動向、顧客調査、価格、今後の進め方を説明します」（目次の読み上げ）
- 良い例:「問い合わせの 6 割を占める 3 種類に絞って自動応答を入れれば、来期の増員なしで応答時間を半分にできるので、来月から試験導入を承認してほしい」

## 素材の仕分け

素材を事実（何が起きているか）、解釈（それが何を意味するか）、行動（だから何をするか）に分ける（空・雨・傘）。根拠が素材にある主張と、ない主張に印を付ける。根拠のない主張は「要確認」にし、数字を補って埋めない。

## ドットダッシュ

主張の文（ドット）と、それを支える根拠（ダッシュ）だけでストーリーラインを書く。並べ方を 2〜3 通り試し、選んだ理由を 1 文で言えるようにする（元マッキンゼー社員のブログ、Knaflic）。導入が要るなら、聞き手が同意している状況 → 起きた問題 → 聞き手が抱く問い → 答え（SCQA）の順に書く。

## タイトル列（ゴーストデッキ）

各スライドについて、設計書に次の 3 つをまず書く。ほかの欄は手順 4 で埋め、見た目はまだ作らない。

1. 答える問い: このスライドが答える読み手の問いを 1 つ
2. タイトル: その問いへの答え（[titles.md](titles.md)）
3. 証拠: 置く図やデータと、比較の種類（[visuals.md](visuals.md)）

答える問いが 1 行で書けないスライドは、二つに分けるかアペンディックスに移す。削るのはアペンディックスに移したあとで判断する（Umbrex）。

## 目的別の並び

ルールシートの目的で既定の並びを選ぶ。すべて実務家の型で、聞き手や社内ルールに合わせて変えてよい。変えたら理由を設計書に書く。

| 目的 | 並び | 出典 |
|---|---|---|
| 決める | エグゼクティブサマリー（判断してほしいことと推奨）→ 背景（最小限）→ 選択肢と比較 → 推奨と理由 → リスクと対策 → 次の一手 → アペンディックス | Umbrex、前田、Atkinson |
| 伝える | 要点のまとめ → 事実 → 解釈 → 示唆と次の一手 → アペンディックス | Umbrex、空・雨・傘 |
| 教える | 何ができるようになるか → 地図（3〜5 項目）→ 既知から未知へ 1 枚 1 概念 → 振り返り | Doumont、Mayer の段階提示 |
| 動かす | 注意を引く導入 → なぜ今大事か → 中核メッセージの予告 → 論点（3 つ、多くて 5 つ）とつなぎ → 振り返り → 結論 → 締め | Doumont |

アジェンダやまとめのスライドは、目次の羅列ではなく、後に続く主張の要約にする。エグゼクティブサマリーを置くなら、その項目を本編のタイトルの順と 1 対 1 で対応させる（Knaflic の水平ロジック）。

## 合格条件

| ID | 条件 | 判定 |
|---|---|---|
| D1 | タイトルだけを順に読むと話が通り、1 段落に要約でき、その要約が中核メッセージと一致する | LLM。文脈を持たないサブエージェントにも読ませる |
| D2 | すべてのスライドで、答える問いが 1 行で書けている | 設計書を見る |
| D3 | エグゼクティブサマリーやアジェンダがあれば、項目が本編のタイトル順と 1 対 1 で対応し、3〜5 項目に収まっている | 設計書を見る |
| D4 | 決める・伝えるデッキで、観察だけで終わるスライドがなく、「だから何か」と「次に何をするか」がデッキ内にある | LLM |
| D5 | 決めるデッキで、懐疑的な聞き手が出しそうな反論を 3 つ書き出し、すべてに本編かアペンディックスで答えている | LLM |
| D6 | 枚数、結論の位置、本文の文字量、タイトルの長さがルールシートどおりで、別のモードの作法が混ざっていない。外れるなら理由が設計書にある | 設計書を見る |
| D7 | ストーリーラインの主張のうち、素材に根拠がないものがすべて「要確認」になっている | 素材と照合 |
