# 図・データ・見た目

図はタイトルの証拠として選ぶ。先にグラフを作って後から解説を付ける順にしない（杉野、Zelazny）。

## 図を選ぶ

タイトルの主張がどの比較をしているかで、図の形を決める（Zelazny、Few）。

| 主張の比較 | 図の形 |
|---|---|
| 全体の中の割合 | 100% 積み上げ棒か円グラフ（項目が多いと円の角度は読み取りにくい。Few） |
| 項目どうしの大小、順位 | 横棒 |
| 時間による変化 | 折れ線（点の数が少なければ縦棒） |
| 分布、ばらつき、二極化 | ヒストグラム、分布曲線 |
| 二つの量の関係 | 散布図 |
| 仕組み、手順、因果 | 図解（箱と矢印、段階） |

- スライドのタイトルには要点を書き、グラフのタイトルには「何のデータか」（記述ラベル）を書く（Velez）
- 写真は実物を見せる必要があるときだけ使う
- 短い列挙は、無理に図にせず箇条書きのままにする（Farkas、中嶋）

## 強調と削減

- 全体をグレーにし、タイトルが名指す対象だけを強調色 1 色で塗る。この強調で、見る人が主結論を捉える確率は約 2.5 倍になった（Ajani ほか 2021、実証）
- 凡例で色を照合させず、系列の端や該当箇所に直接ラベルを付ける（Mayer の空間的近接、実証）
- タイトルを支えない要素を消す（Mayer の一貫性、実証）。枠線やグリッド線を消すデクラッターは見た目の信頼感のためで、それだけでは理解は上がらない（Ajani ほか 2021）
- 意味のある図像は記憶を助けることがあるが、データの背後に敷く画像は解釈を妨げる（Bateman ほか 2010、実証）。意味のない飾りの絵は置かない
- 投影では、図の部分を話す順に出す（Mayer の段階提示）。描画形式がアニメーションに対応していなければ、スライドを分けて代える

## 書体と組版（日本語）

出典はすべて『伝わるデザイン』（高橋・片山）の経験則で、日本語スライドについての実証研究はない。

- 太字に対応したゴシック体を使う（メイリオ、游ゴシック、BIZ UD ゴシック、ヒラギノ角ゴシック、Noto Sans JP）。欧文はサンセリフで揃える
- MS ゴシック、擬似ボールド、日本語の斜体、長体・平体を使わない
- 行間は文字サイズの約 70%（行送り約 1.7 倍）、字間は約 5%
- 揃えは左揃えを基本にし、1 枚の中で揃え方を混ぜない
- 文字サイズの段階は 2〜3 に絞る

## 色

- 色は 4 色まで（背景、文字、メイン、強調）。強調は 1 色（『伝わるデザイン』、経験則）
- 色だけで区別させない。赤と緑の対比を避け、形、線種、直接ラベルを併用する。日本人男性の約 5% が先天的な色覚の特性を持つとされる
- コントラスト比は文字で 4.5:1 以上、図の線や面で 3:1 以上（WCAG 2.2 の 1.4.3 と 1.4.11、規範）。投影では会場の明るさでコントラストが落ちるので余裕を持たせる

## 頼まれていない装飾を足さない

AI が作ったスライドに見える特徴として、日本語と英語の実践者が次を挙げている（為安、ふじくるり、菊池、Plus AI）。Anthropic の pptx スキルも、タイトル下の線を「AI 生成スライドの特徴」と書いている。テンプレートやブランド規定で求められていない限り使わない。

- タイトル下の線、色の帯
- 丸い背景に入れたアイコン、絵文字のアイコン
- 英字の小見出し（タイトルの上の小さな英語）、斜体の飾り文字
- 同じ幅のカードを 3 枚並べる型の繰り返し
- 文脈のない巨大な数字、背景を埋める写真

レイアウトは内容の構造（比較、時系列、手順、一つの図）から選ぶ。前のスライドと同じ型にするのは、内容の構造が同じときだけ。

## 合格条件

| ID | 条件 | 判定 |
|---|---|---|
| F1 | タイトルの述語と図の形が合っている（二極化なら分布、増加なら時系列、差なら項目の比較） | 描画した画像を LLM が見る |
| F2 | タイトルが名指す対象だけが強調色で、ほかは控えめな色になっている | 画像を見る |
| F3 | 消してもタイトルの裏付けが弱くならない要素が残っていない | LLM |
| F4 | タイトルの断定の強さが証拠に見合う。印象や少数の事例に一般化した断定を、相関に因果のタイトルを付けていない | LLM |
| F5 | すべての数字が素材にあり、計算した数字は再計算で一致する | 素材と照合 |
| V1 | 投影で、話す文の全文がスライドに載っていない（2〜3 語のラベルは可） | 発表者ノートと照合 |
| V2 | グラフの系列や図の部位に直接ラベルがある | 画像を見る |
| V3 | 色は 4 色程度で強調は 1 色、赤と緑の対比がなく、色以外でも区別できる | 画像を見る |
| V4 | 文字は 4.5:1 以上、図の要素は 3:1 以上のコントラストがある | 色の値から計算する |
| V5 | 書体と組版が上の既定（英語のスライドはサンセリフで揃える。ルールシートに外部規定があればそれ）どおり | 描画データか画像を見る |
| V6 | 文字サイズがルールシートの最小以上で、収めるために縮小していない | 描画データを見る |
| V7 | 頼まれていない装飾がない（ルールシートの外部規定で求められたものは除く） | 画像を見る |
| V8 | 全スライドを画像にして、はみ出し、重なり、プレースホルダーの残りがないことを見た。画像にできない形式なら、納品時にそう書く | 画像を見る |
