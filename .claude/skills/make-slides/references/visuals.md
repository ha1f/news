# 図・データ・見た目

図はタイトルの証拠として選ぶ。先にグラフを作って後から解説を付ける順にしない（杉野、Zelazny）。

## 図を選ぶ

タイトルの主張がどの比較をしているかで、図の形を決める（Zelazny、Few）。

| 主張の比較 | 図の形 |
|---|---|
| 全体の中の割合 | 100% 積み上げ棒（円グラフは Zelazny が使う一方、Few は角度で値を読ませる表現を勧めない） |
| 項目どうしの大小、順位 | 横棒 |
| 時間による変化 | 全体の傾向を見せるなら折れ線、個々の値を見せるなら縦棒（Few） |
| 分布、ばらつき、二極化 | ヒストグラム、分布曲線 |
| 二つの量の関係 | 散布図 |
| 仕組み、手順、因果 | 図解（箱と矢印、段階） |

- スライドのタイトルには要点を書き、グラフのタイトルには「何のデータか」（記述ラベル）を書く（Velez）
- 素材にデータがない形（分布の山、推移の線など）を描くときは「イメージ図」と明記し、データに見せない。根拠のない因果に矢印を付けない（為安）
- 写真は内容を示すとき（実物、現場、人）に使い、背景を埋めるためだけには使わない
- 短い列挙は、無理に図にせず箇条書きのままにする（Farkas、中嶋）
- 数件の事例（インタビュー数社など）は件数のグラフにせず、引用か列挙で示す。グラフにすると数件が量的なデータに見え、証拠より強い主張になる（考え方 3、F4）

## 強調と削減

- 全体をグレーにし、タイトルが名指す対象だけを強調色 1 色で塗る。表でも同じで、名指す行かセルだけを強調し、主張に関わらない列はアペンディックスに回す。名指す先を決められないなら主張がまだ決まっていないので、図を作り込まずにタイトルの決め方に戻る。対比色と結論の見出しを一緒に加えると、見る人が主結論を捉える確率は約 2.5 倍になった（Ajani ほか 2021、実証。色だけの効果は測っていない）。同じ実験で押し付けと感じて信頼を下げた人もいたので、強調は主張の一点に絞り、データの限界は注記で示す
- 凡例で色を照合させず、系列の端や該当箇所に直接ラベルを付ける（Mayer の空間的近接、実証）
- タイトルを支えない要素を消す（Mayer の一貫性、実証）。枠線やグリッド線を消すデクラッターは見た目の信頼感のためで、それだけでは理解は上がらない（Ajani ほか 2021）
- 意味のある図像は記憶を助けることがあるが、データの背後に敷く画像は解釈を妨げる（Bateman ほか 2010、実証）。意味のない飾りの絵は置かない
- 投影では、図の部分を話す順に出す（Mayer の段階提示）。要点と関係のない動きのアニメーションは使わない。描画形式がアニメーションに対応していなければ、スライドを分けて代える

## 書体と組版（日本語）

出典はすべて『伝わるデザイン』（高橋・片山）の経験則で、日本語スライドについての実証研究はない。

- 太字に対応したゴシック体を使う（メイリオ、游ゴシック、BIZ UD ゴシック、ヒラギノ角ゴシック、Noto Sans JP）。MS ゴシック、HG ゴシック、MS 明朝、擬似ボールド、日本語の斜体、長体・平体を使わない
- 欧文はサンセリフにし、和文と見た目の大きさと太さを揃える（メイリオに Calibri を合わせると欧文が小さく見えるので、Segoe UI などにする）
- 行間は文字サイズの約 70%（行送り約 1.7 倍）、字間は約 5%
- 揃えは左揃えを基本にし、1 枚の中で揃え方を混ぜない
- 文字サイズの段階は 2〜3 に絞る

## 色

- 色は 4 色まで（背景、文字、メイン、強調）。強調は 1 色（『伝わるデザイン』、経験則）
- 同じ対象はデッキ全体で同じ色にし、タイトルや本文でその対象に触れるときもグラフの系列と同じ色を使う。タイトルが名指さない系列に強調色を使わない（Knaflic、『伝わるデザイン』）
- 描画ツールの既定の配色（高彩度の標準色、既定の青、全面のダーク背景、クリーム地）をそのまま使わず、メインは落ち着いた色にしてデッキで固定する。明度が近く彩度の高い色どうしを隣に置かない（『伝わるデザイン』、AI が作ったスライドの特徴として実践者も挙げる）
- 色だけで区別させない。赤と緑の対比を避け、形、線種、直接ラベルを併用し、同系色は明度に差を付ける。日本人男性の約 5% が先天的な色覚の特性を持つとされる
- コントラスト比は、文字で 4.5:1 以上（18pt 以上か、太字 14pt 以上の文字は 3:1 以上）、図の線や面で 3:1 以上（WCAG 2.2 の 1.4.3 と 1.4.11、規範。ウェブ向けの基準で、スライドへの言及はない）

## 頼まれていない装飾を足さない

主張を支えない装飾は、支えないだけでなく注意を奪う（考え方 2、F3）。次の装飾は AI が作ったスライドによく出るものとして、日本語と英語の実践者が挙げている（為安、ふじくるり、菊池、Plus AI。Anthropic の pptx スキルもタイトル下の線や装飾の色帯を挙げる）。テンプレートやブランド規定で求められていない限り使わない。リストにない装飾も、主張を支えるかで判断する。

- タイトル下の線、色の帯
- 丸い背景に入れたアイコン、絵文字のアイコン
- 英字の小見出し（タイトルの上の小さな英語）、斜体の飾り文字
- 同じ幅のカードを 3 枚並べる型の繰り返し
- 文脈のない巨大な数字、背景を埋める写真

レイアウトは内容の構造（比較、時系列、手順、一つの図）から選ぶ。前のスライドと同じ型にするのは、内容の構造が同じときだけ。

## 描画後の確認

全スライドを画像にして確かめる。描画した本人には描画されたものではなく意図した姿が見えるので、画像は描画していない、文脈を持たないサブエージェントに渡す（Anthropic の pptx スキル、広木）。渡すのは聞き手が受け取るものだけ（投影なら発表者ノートも）と、ルールシートの聞き手の役（役職、前提知識）で、次の三つを頼む。サブエージェントを使えない環境では自分で見て、納品時にそう書く。

1. 各スライドの画像から要点を 1 文で書く。設計書のタイトルと照合し、ずれたスライドは F1・F2 で不合格にする
2. V8 の見た目の欠陥を探す
3. 聞き手として読んだ後に取れる行動、足りない情報、意味のわからない語を書く（D10）

描画物からテキストを抜き出し、設計書と照合する（V10）。LibreOffice で画像にすると、手元にないフォントが幅の違うフォントに置き換わり、はみ出しの判定が狂うことがある。

## 合格条件

| ID | 条件 | 判定 | 考え方 |
|---|---|---|---|
| F1 | タイトルの述語と図の形が合っている（二極化なら分布、増加なら時系列、差なら項目の比較）。画像から読み取った要点がタイトルと一致する | 設計書で確かめ、描画後に画像で再確認 | 3 |
| F2 | タイトルが名指す対象だけが強調色で、ほかは控えめな色になっている。同じ対象はデッキ全体で同じ色 | 画像を見る | 2 |
| F3 | 消してもタイトルの裏付けが弱くならない要素が残っていない | LLM | 2 |
| F4 | タイトルの主張がそのスライドの図や本文で裏付けられ（スライドにないことをタイトルで言わない）、断定の強さも証拠に見合う。印象や少数の事例に一般化した断定を、相関に因果のタイトルを付けていない | LLM | 3 |
| F5 | スライドの事実と数字がすべて素材にあり（調べて足したものは出典付きで「要確認」）、計算した数字は再計算で一致する | 素材と照合 | 3 |
| F6 | 素材にデータがない形を描いた図に「イメージ図」と明記されている。根拠のない因果に矢印がない | LLM | 3 |
| V1 | 文字量がルールシートどおり。投影では話す文の全文がスライドに載っていない（短いラベルやキーワードは可） | 発表者ノートと照合 | 4 |
| V2 | グラフの系列や図の部位に直接ラベルがある | 画像を見る | 2 |
| V3 | 色は 4 色程度（目安）で強調は 1 色、既定の配色をそのまま使っていない。赤と緑の対比がなく、グレースケールにしても区別できる | 画像をグレースケールにして見る | 1・2 |
| V4 | コントラスト比が上の基準を満たす | 色の値から計算する | 1 |
| V5 | 書体と組版が上の既定（英語のスライドはサンセリフで揃える。ルールシートに外部規定があればそれ）どおり。行間・字間の値は目安 | 描画データか画像を見る | 1・2 |
| V6 | 文字サイズがルールシートの最小以上（出典や注記の行は除く。値は目安）で、収めるために縮小していない | 描画データを見る | 1・4 |
| V7 | 頼まれていない装飾がない（ルールシートの外部規定で求められたものは除く） | 画像を見る | 2 |
| V8 | はみ出し・切れ、重なり、余白の不足、整列のずれ、同種のスライドでのタイトル位置のずれ、語や「数値と単位」の途中での改行、小さすぎて読めない図、プレースホルダーの残りがない | 画像を見る | 1 |
| V9 | 投影で、アニメーションは図の部分を話す順に出すためだけに使っている | 描画データを見る | 2 |
| V10 | 描画物から抜き出したタイトル・数字・順序が設計書と一致し、lorem、TODO、プレースホルダーの文字が残っていない | テキストを抜き出して照合 | 3 |
| V11 | 内容の構造が違うのに、同じレイアウトが 3 枚以上続いていない（枚数は目安） | 画像を並べて見る | 2 |
