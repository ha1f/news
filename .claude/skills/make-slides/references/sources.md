# 出典

references で略称で挙げた出典の一覧。スライドを作るときに読む必要はなく、ルールを見直すときと、ユーザーに根拠を聞かれたときに使う。調査の全体（約 150 の原則、出典どうしの食い違い、確認できなかった点）はこの repo の `reports/スライド設計とタイトルの原則.md` と `research_notes/スライド設計とタイトルの原則/` にある。

根拠の種類: 実証 = 統制実験 ／ 規範 = 組織・教育機関のルール ／ 経験則 = 実務家個人の主張

## 実証

| 略称 | 内容 | リンク |
|---|---|---|
| Garner & Alley 2013 | 主張見出し＋図＋少ない文字は、トピック見出し＋箇条書きより理解（d=0.81）と 1 週間後の想起（d=0.89）が高い。n=110。三つの要素を同時に変えている | [IJEE](https://www.ijee.ie/articles/Vol29-6/23_ijee2791ns.pdf) |
| Alley 2006 | 文の見出しはフレーズの見出しより主張の想起が高い（79% 対 69%） | [ASEE](https://peer.asee.org/testing-the-effect-of-sentence-headlines-in-teaching-slides.pdf) |
| Farkas 2010 | Alley への反論。対照群の質が低く、すべての主張に図を求めるのは過剰。文の見出し自体は支持 | [Farkas](https://faculty.washington.edu/farkas/dfpubs/Farkas-Assessment%20Of%20Alleys%20Slide%20Design.pdf) |
| Mayer | マルチメディア学習の原則（一貫性、信号化、空間的近接、冗長性、段階提示）。冗長性の効果量は版によって 0.86 から 0.10 まで揺れる | [Mayer 2017](https://zendy.io/title/10.1111/jcal.12197)、[UNH 配布資料](https://www.unh.edu/teaching-learning-resource-hub/sites/default/files/media/2023-06/itow-research-based-principles-for-designing-multimedia-instruction-mayer.pdf) |
| Ajani ほか 2021 | 伝えたい系列だけを強調すると主結論を捉える確率が約 2.5 倍。デクラッターだけでは理解は変わらない。n=24 | [Kellogg Insight](https://insight.kellogg.northwestern.edu/article/do-people-understand-your-data-visualizations) |
| Bateman ほか 2010 | 装飾付きグラフは読み取りの正確さが同等で、後日の想起が良い。背景画像は解釈を妨げる | [CHI 2010](https://vis.csail.mit.edu/classes/6.859/readings/pdfs/Bateman-UsefulJunk.pdf) |
| Yahoo!ニュース | トピックスの見出しは 11 → 13.5 → 14.5 → 15.5 字と延長。社内調査で 15 字以上のほうが内容を正確に理解された（査読なし） | [news HACK 2021](https://news.yahoo.co.jp/newshack/info/yahoonews_topics_heading14.html)、[2022](https://news.yahoo.co.jp/newshack/info/yahoonews_topics_heading15.html) |
