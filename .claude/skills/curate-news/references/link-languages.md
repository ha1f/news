# リンク先の言語（ソース定義の無いサイト）

アグリゲータ（はてブ等）経由の項目で、リンク先にソース定義が無いサイトの言語の一覧（#708）。ソース定義の記事ドメインに一致しないリンクは、ここに載っていればその言語を使い、載っていなければアグリゲータ自身の言語を使う。はてブは日本語が既定なので、英語のサイトはここに載せないと `(はてブ)` と出て、日本語の記事に見える。ラベルの付け方は curate-news の SKILL.md「ソース名と読者向け属性」を参照。

`check_source_hints.py` がこの一覧を正規表現で読む。

- 行の形は `` - `{ドメイン}`: {言語} ``。`www.` は付けない。ドメインはサブドメインにも一致する（`claude.com` は `support.claude.com` にも一致する）
- URL のパスの区切りに `ja` / `jp` / `ja-jp` があるページ（`claude.com/ja/…`、`…/docs/ja/…`）と `?hl=ja` 等のページは、日本語版として扱い、この一覧を当てない
- 載せるサイトは無料で読めるものとして扱い、言語だけをラベルにする
- ソース定義の記事ドメインと同じドメインは載せない（ソース定義が先に一致するので効かない。検査が NG で止まる）
- 言語は `<html lang>` で確かめてから載せる
- 一覧に無い英語のサイトが `(はてブ)` のまま配信されているのに気づいたら、評価・レビュー・開発のどの run でも、この一覧に1行足す PR を出す（配信の run は `_posts/` しか commit しないので、そこでは足さない）。同じ PR で、`check_source_hints.py --all` が新たに出す不一致のうち、その投稿の本文に他の不一致が無いものはラベルも直す（他の不一致がある古い投稿は、本文に触ると CI が無関係の違反で落ちるので触らない）
