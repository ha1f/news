# remove-ai-tells

対象の文章（ファイルか貼り付けたテキスト）を、その言語を母語とする有能な書き手が書いたように読める文章に直す。読み手が「AI が書いた」と感じて中身を割り引くのを防ぐのが目的で、AI 判定ツールを通すことは目的にしない。表面の癖だけ消しても、中身の空疎さは見つけにくくなるだけで残る。

観点は言語をまたぐものを [references/common.md](references/common.md) に、言語固有のものを [references/en.md](references/en.md) と [references/ja.md](references/ja.md) に置いてある。common.md は常に読み、言語別は対象の言語のものだけ読む（日英が混ざる文章なら両方）。それ以外の言語は common.md だけで進め、言語固有の観点がないことを結果に書く。

## 書き換えるときに守ること

- 事実を足さない。抽象的な言い回しを具体的にしたくても、使える事実が文書のほかの箇所や会話になければ、作らずに書き手への質問にする（「具体的に書け」という方針は捏造を招く）
- 数字・固有名詞・否定・限定表現（約、数名、may、can、主に など）は変えない。限定表現は、書き手が意図して入れた範囲の制限であることが多い
- 候補を全部直さない。1 回の出現はたいてい偶然で、兆候になるのは密度と繰り返し。変更なしも正しい結果になりうる
- 同義語への置き換えや、別の揃った型への並べ直しは直したことにならない。具体的な事実か、平易な構文で直す
- ジャンルの慣習（レジュメの動詞始まり、技術文書の並列、メールの定型の挨拶）、引用、固有名詞、コードは対象外
- 会話や CLAUDE.md にユーザーや repo の文体規約があれば、references より優先する
- 書き換えた文章にも自分の癖（ダッシュ、三点セット、決め台詞）が入る。書き換え後にも検出をかける
- 書き換えの採否を、別の LLM に「どちらが人間らしいか」を採点させて決めない。LLM の文章の良し悪しの判定は偶然に近い。事実が保たれたかは `--compare` の差分で確かめ、自然に読めるかは書き手本人が対応表を見て決める

## 手順

1. 範囲と制約を確かめる: 言語、ジャンル、読み手、変えてはいけないもの（長さの上限、必須のキーワード、固有名詞、口調）。分からない点は聞くか、仮定を明記して進める
2. 書き換える前の版を一時ファイルに写す（置き場所は環境やユーザーの指定に従う）。この写しは手順 5 の比較にだけ使い、編集しない。貼り付けられたテキストは、写しとは別の一時ファイルにも書き、そちらを編集の対象にする
3. 候補を検出し、references の観点に照らして、候補ごとに直すか残すかを決める。スクリプトは候補を返すだけで判定はしない。日英が混ざる文章は `--lang ja,en` のように両方を指定する（1 言語だけだと、もう一方のパターンが当たらない）。出力の `judgment_checks` に並ぶ観点は正規表現では拾えないので、references の該当項目を読んで全文から探す。出力の読み方は common.md の「スクリプト出力の読み方」にある

   ```bash
   python3 ${CLAUDE_SKILL_DIR}/scripts/detect_tells.py <file>
   ```

4. 書き直す。ファイルは該当箇所だけを編集し、全体を書き直さない（差分が読めなくなり、手順 5 の比較も効かなくなる）。事実が足りない箇所は質問として残す
5. 検証する。書き換え前後を比べ、意図しない差分があれば戻す。書き換え後の文章にも検出をかけ、新しく入った癖（繰り返しの言い回しなど）を直す。読み方は手順 3 と同じ節にある

   ```bash
   python3 ${CLAUDE_SKILL_DIR}/scripts/detect_tells.py --compare <書き換え前の写し> <書き換え後>
   python3 ${CLAUDE_SKILL_DIR}/scripts/detect_tells.py <書き換え後>
   ```

   増えた数字は捏造の疑いとして最初に確かめる。消えた否定や限定表現は意味の変化
6. 提示する: 書き直した文章と、次の対応表。候補に挙がったが残したものも載せる（残した理由が見えないと見落としと区別できない）。id のない指摘（コードコメントの言い換えなど）は、観点の欄に common.md の節名を書く。直せずに質問にした箇所は表の下に並べる。変更がなかったときは、そう書いたうえで同じ表を示す

   | 元の表現 | 書き換え後 | 観点 (id) | 扱い | 理由 |
   |---|---|---|---|---|
   | `...` | `...` | en-participial-significance | 変換 / 削除 / 残す | 1 行 |
