プロンプト（SKILL.md、CLAUDE.md、`.claude/rules/` 配下のファイル等）を新規作成・編集した後は、`/improve-prompt` を実行して品質を確認する。

実行するかは編集量でなく**何を編集したか**で決める。エージェントが読んで従う手順・指示を変えたなら1行でも実行し、説明・背景・理由だけなら不要。手順を変えたときは机上シミュレーション（改訂後の該当箇所だけを fresh context の subagent に渡し、そのとおり実行させて詰まる所を報告させる）まで通す。「手順どおりに実行できない」「同じ節の中で指示と説明が矛盾する」は、diff と主張を突き合わせるレビューでは捕まらない。
